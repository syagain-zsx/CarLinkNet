网络与信息安全专业

摘要 随着网络环境日益复杂，网络流量行为在时间结构、交互模式及通信形态等方面呈现出更加复杂的特征，使得基于单一特征视角或单一检测模型的方法难以全面刻画网络会话的整体行为模式，在多类别攻击场景下检测性能易受到限制。针对上述问题，本文围绕网络流量的多视图特征建模与集成学习检测方法开展研究，设计了一种面向网络恶意流量检测的多视图集成检测方法。
（1）针对单一特征视角表征能力有限的问题，本文从统计特征、行为时间结构特征以及多尺度频域特征三个视图对网络会话行为进行刻画，构建了多视图网络流量特征表示，以增强对通信行为的整体表征能力。
（2）针对单一检测模型对多视图特征信息利用不足的问题，本文设计了多分支检测模型结构，对不同特征视图分别进行建模与判别。在此基础上，设计了一种基于粒子群优化的投票方法，通过调整不同模型在各类别上的投票权重，实现模型的集成检测，提升整体检测性能。 08

## 1.1 研究背景与意义
近年来，互联网技术的快速发展使网络空间逐渐成为社会运行的重要基础设施，网络规模与用户数量持续增长。据《第 55次中国互联网络发展状况统计报告》<sup>[1]</sup>统计，截至 2024年12月，我国网民规模达 11.08亿人，较 2023年12月增长1608万人，其变化趋势如图1.1 我国网民规模及互联网普及率变化趋势所示。但庞大的网络规模伴随着严峻的安全威胁：网络流量中潜藏的恶意流量给个人隐私、企业机密乃至国家安全都带来巨大风险。例如，2022年西北工业大学电子邮件系统遭受境外攻击者通过钓鱼邮件投递木马程序，造成邮件数据泄露；2023年中国工商银行旗下工银金融服务有限责任公司（ICBCFS）亦遭受勒索软件攻击，导致部分业务系统中断。这些攻击事件往往通过恶意网络通信实现远程控制、数据窃取或横向传播，因此对网络通信流量进行有效监测与分析成为网络安全防护的重要手段。

网络恶意流量检测的目的，是在海量网络通信数据中及时识别潜在的攻击行86为或异常活动，为后续响应决策提供精准依据。近年来网络攻击技术不断演化，恶意通信行为的隐蔽性与复杂性不断提升<sup>[2]</sup>。传统方法主要包括基于签名特征匹配的滥用检测技术，以及基于行为建模的异常检测方法[3]。前者虽然在处理已知测攻击样本方面表现良好，但对新型攻击或变种攻击缺乏适应能力；后者虽具一定<sub>泛化能力，但在复杂真实网络环境中，流量数据往往具有高维度、类别分布不均</sub>质衡以及数据分布动态变化等特征，这些因素都会对检测模型的稳定性和泛化能力论造成影响，从而导致误报率升高、检测性能波动等问题。此外，随着 HTTPS、TLS等加密通信协议的广泛应用，网络通信内容逐渐不可见，传统依赖载荷信息进行特征分析的检测方法面临新的挑战，其有效性逐渐下降，迫切需要能够适应流量特征变化的检测机制<sup>[4]</sup>。

针对上述挑战，学术界与工业界纷纷将目光投向更为智能化的检测策略。近年来，融合多源信息、多角度建模的思路被广泛认可，尤其是在网络流量异常检测场景中，多视图特征建模方法显示出优势。相较于单一特征建模方式，多视图融合策略能够从统计行为、时序演化以及通信结构等多个维度对网络流量进行建模<sup>[5]</sup>，从而获得更加全面的流量行为表示。例如部分研究通过在加密通信场景下引入握手证书特征、包间统计特征等作为替代信息，用于提升恶意加密流量识别能力<sup>[6]</sup>。
此外，在特征融合与模型集成方面，越来越多的研究尝试构建多分支或多模块结构以集成不同子模型的识别能力，形成更具泛化性能的综合检测框架<sup>[7]</sup>。通过对不同视角下提取的流量特征进行有效融合，可以实现对网络通信行为更加全面的刻画，有助于提升对恶意流量的检测能力。如何从多维度流量特征中提取有效信息，并以此构建系统化的检测平台，正在成为网络安全技术演进的重要方向。
基于上述研究背景，针对当前恶意流量检测中存在的特征表达能力不足以及检测模型适应性有限等问题，本文围绕多视图特征建模与集成学习方法展开研究，设计并实现一种面向复杂网络环境的恶意流量检测系统。该系统通过构建多维度流量特征表示并结合模型集成策略，以提升对复杂攻击行为的识别能力。
## 1.2 国内外研究现状
## 1.2.1 恶意流量检测方法研究现状
在日益复杂的网络安全环境中，恶意流量成为威胁网络稳定运行的主要因素0之一。如何有效识别伪装性强、变化迅速的攻击流量，是当前网络安全防御体系<sup>—</sup>中的核心挑战。围绕这一问题，研究者从传统规则匹配方法起步，逐步演进至以26深度学习与集成模型为基础的智能检测方法[8]。本文从技术演进视角出发，对当4前主流的恶意流量检测方法进行梳理，以揭示其发展脉络与研究趋势。8
网络恶意流量检测技术经历了从规则匹配到深度智能学习的发展演进，反映了网络攻防对抗日益复杂化的技术趋势。早期检测方法主要依赖特征匹配机制，即误用检测（Misuse Detection）思想。该类方法通过预定义攻击特征或规则对网测络数据进行模式匹配，以识别已知攻击行为。典型代表如入侵检测系统 Snort，它量基于规则库进行数据包深度分析，能有效识别签名攻击并保持较低误报率。但由于其对未知攻击无能为力，且特征库维护成本较高，难以适应攻击手段频繁演变论

为解决特征匹配的局限，异常检测方法逐渐引入流量检测领域。该类方法通过构建正常流量行为模型，在此基础上识别偏离行为以发现潜在威胁。异常检测具备发现未知攻击的能力，但易受环境噪声干扰，误报率偏高，检测准确性和实用性尚需权衡。特征匹配与异常检测分别代表了传统入侵检测系统的两种主流路径，前者具备明确性和精确性，后者侧重普适性与泛化能力，但二者在检测覆盖与准确性上均存在瓶颈，这推动研究者寻求更加智能化的流量分析手段。
随着机器学习的发展，基于分类器的恶意流量检测方法逐渐兴起。Moore 等人引入无载荷特征（如包长分布、方向序列、到达时间间隔）建立基于贝叶斯分类的流量识别框架，为攻击识别提供了数据驱动的路径<sup>[10]</sup>。国内如肖警等提出自适应勒索病毒检测模型，通过深度分析与特征提取增强对攻击变种的识别能力，体现出机器学习技术对恶意行为建模能力的优势<sup>[11]</sup>。
近年来，深度学习成为恶意流量检测的主流方向。该类方法通过构建多层神经网络自动提取流量特征，克服了传统模型对专家经验和特征工程的依赖。Zhao等提出结合信息熵分析和深度强化学习的恶意流量检测模型，利用特征重要性剔除冗余项，并通过 PPO 算法提升检测策略的智能性<sup>[12]</sup>。Zang 等借助自然语言处理（NLP）思想，将数据包头视为“字节序列”，采用关键词提取机制捕捉语义特征，有效提升加密流量中隐匿攻击行为的识别能力<sup>[13]</sup>。Huang 等提出 BSTFNet模型，通过引入 BERT 机制提取全局语义、结合 BiGRU 与 TextCNN 分别建模时序与局部空间特征，实现了对加密流量的多粒度建模和分类<sup>[14]</sup>。

## 2.1 网络流量概述
随着互联网基础设施的不断完善以及各类网络应用的广泛部署，网络环境中承载的通信行为呈现出规模大、类型多、变化快等特点。网络流量作为网络中数据传输活动的直接体现，集中反映了网络运行状态、业务负载特征以及通信实体之间的交互关系，是开展网络性能分析与安全检测的重要数据基础。通过对网络流量进行系统分析，可以有效识别网络中的异常行为，为入侵检测与安全防护提供关键依据<sup>[27]</sup>。
从数据层面来看，网络流量是指在一定时间范围内，网络节点之间依据通信协议所交换的数据集合。根据分析目标和建模方式的不同，网络流量通常可以在多个粒度层面进行表示。其中，数据包（Packet）是最基本的组成单元，能够精确刻画单次通信过程中的协议字段和载荷信息，但其数量庞大、时序离散性强，在复杂网络环境中直接建模往往面临计算开销大和噪声干扰严重等问题<sup>[28]</sup>。为提高分析效率并增强行为表征能力，研究与实践中通常将数据包按照通信五元组及时间约束进行聚合，构建网络流（Flow）或会话（Session）级数据表示。相较于数据包级表示，流量级表示能够更全面地反映通信过程中的统计特性、时序关系与交互模式，已成为当前网络流量分析与异常检测研究中的主流建模对象<sup>[29]</sup>。
在实际网络环境中，网络流量具有显著的动态性和非平稳性特征<sup>[30]</sup>。一方面，正常业务流量在不同时间尺度下呈现出周期性波动、突发变化以及负载不均衡等现象；另一方面，异常或恶意流量往往通过调整通信频率、数据分布或交互模式来规避检测机制，使其行为特征在短时间内发生明显变化<sup>[31]</sup>。这种复杂多变的流量特性使得仅依赖原始流量数据或单一统计指标难以准确刻画通信行为的本质特征，从而对后续的异常识别与入侵检测提出了更高要求。 02
因此，在网络安全检测任务中，网络流量不仅是研究对象的直接载体，也是<sup>—</sup>特征构建与模型设计的基础来源。如何从原始流量数据中提取具有判别力的特征26表示，充分挖掘流量在统计分布、时序结构以及多尺度变化等方面所蕴含的信息，4是提升检测性能的关键问题[32]。上述分析为后续流量特征工程方法的研究与设计8奠定了基础。

## 2.2.3 多视角特征建模
复杂网络环境中，网络流量行为往往同时呈现出多层次、多尺度的特征属性，其表现形式既包含整体分布特性，也体现出随时间演化的动态变化规律。单一视角下的特征描述通常只能反映通信行为的某一侧面，难以全面刻画网络流量在不同层次上的行为特征。因此，仅依赖单一类型特征进行建模，往往难以适应复杂多变的网络攻击场景<sup>[42]</sup>。
从整体层面进行描述时，流量特征能够反映通信会话在规模和分布形态上的宏观特性，但对通信过程中细粒度行为变化的刻画能力有限；引入时间维度后，特征建模能够进一步揭示通信行为在交互节奏和演化过程中的动态特征，但对长期趋势和多尺度变化的表达仍存在一定局限；而从多尺度角度对流量行为进行分析，则有助于刻画通信过程中的周期性和突发性变化，但单独使用时难以完整反映通信行为的整体结构<sup>[43]</sup>。
已有研究表明，不同层面的特征在信息表达能力和适用场景上具有明显的互补性。通过从多个视角对网络流量进行特征建模，可以在一定程度上弥补单一视角描述的不足，更全面地刻画通信行为在宏观分布、时间演化以及多尺度变化等方面的综合特性，从而提升入侵检测系统对复杂和隐蔽攻击行为的识别能力<sup>[44]</sup>。
综上所述，多视角特征建模并非对特征数量的简单叠加，而是一种结合不同分析视角以增强行为表达能力的建模思想。

## 2.5 粒子群优化算法
粒子群优化算法（Particle Swarm Optimization，PSO）是一种典型的群体智能优化算法，由 Kennedy 和Eberhart于 1995年提出。该算法受到自然界鸟群觅食行为的启发，通过模拟群体中个体之间的信息共享与协同搜索过程，实现对复杂优化问题的求解。由于其原理简单、参数较少且易于实现，PSO已被广泛应用于函数优化、参数调优以及特征选择等领域<sup>[60]</sup>。

粒子群优化算法的基本思想是将待优化问题的潜在解表示为粒子群中的个体，每个粒子在搜索空间中具有当前位置和速度。在迭代过程中，粒子根据自身历史最优位置以及群体全局最优位置不断调整运动方向，从而在搜索空间中逐步逼近最优解。通过个体经验与群体协作相结合的方式，PSO能够在全局搜索能力和收敛速度之间取得较好的平衡。
从形式上看，设第�个粒子在第�次迭代中的位置和速度分别为 $\mathbf { \Delta x } _ { i } ^ { t }$ 和 $\mathbf { \epsilon } \lvert \mathbf { v } _ { i } ^ { t }$ ，其速度与位置更新过程可表示为：
$$
\mathbf {v} _ {i} ^ {t + 1} = \omega \mathbf {v} _ {i} ^ {t} + c _ {1} r _ {1} (\mathbf {p} _ {i} - \mathbf {x} _ {i} ^ {t}) + c _ {2} r _ {2} (\mathbf {g} - \mathbf {x} _ {i} ^ {t}),\tag{2.5}
$$
$$
\mathbf {x} _ {i} ^ {t + 1} = \mathbf {x} _ {i} ^ {t} + \mathbf {v} _ {i} ^ {t + 1}.\tag{2.6}
$$
其中， $\mathbf { p } _ { i }$ 表示粒子自身历史最优位置， $\mathbf { g }$ 表示群体全局最优位置， $\omega$ 为惯性权重， $c _ { 1 }$ 和 $| c _ { 2 }$ 分别为个体学习因子与群体学习因子， $r _ { 1 }$ 和 ${ { 1 } { r _ { 2 } } }$ 为服从均匀分布的随机数。
粒子群优化算法通过引入惯性权重与学习因子，在一定程度上兼顾了全局搜索能力与局部搜索能力。较大的惯性权重有助于增强算法的全局探索能力，而较小的惯性权重则有利于算法在局部区域内精细搜索。通过合理设置相关参数，PSO能够有效避免陷入局部最优解，提高优化结果的稳定性<sup>[61]</sup>。

## （2）时序波动特征

## （4）行为基线偏离特征

## （1）概述
在多视图特征检测框架中，不同基础分类模型分别基于结构统计特征、行为时间结构特征与多尺度频域特征进行建模，其在不同攻击类型与数据分布条件下的判别能力存在显著差异。传统单模型检测方法难以同时兼顾多类流量行为特征，而常见的投票或平均集成策略通常假设各模型在所有类别上的贡献等价，忽略了模型在特定攻击类型上的性能差异<sup>[14],[16]</sup>。在类别不平衡或攻击行为差异显著的应用场景中，这种统一权重的集成方式可能限制整体检测性能的进一步提升。

## （2）类别加权投票机制设计
对应图 3.4 中的投票模块，本文采用一种类别级加权集成投票机制对多模型预测结果进行集成。与传统 soft voting 仅为每个模型分配一个全局权重不同，该机制针对不同攻击类别分别学习模型权重，以刻画不同模型在各类别上的差异化判别能力。
具体而言，对于每一个输入样本，三个基础模型均输出其属于各攻击类别的预测概率。集成阶段根据预先学习得到的类别级权重，将这些预测概率按类别在模型之间进行加权组合，最终得到一组集成后的类别概率分布，并据此完成最终分类决策。

## 4.1 系统需求分析
在复杂网络环境下，恶意流量呈现出结构多样化与行为隐蔽化特征，传统单一特征或单模型检测方法难以实现稳定泛化<sup>[75]</sup>。基于第三章设计的多视图特征模型集成方法，为验证其工程可行性并支撑实际应用需求，有必要设计并实现一套与之相匹配的网络恶意流量检测系统。该系统用于承载多视图特征构建、多模型协同检测及结果集成机制，实现方法层向工程层的有效转化。
从系统需求角度分析，本文设计的检测系统需满足以下三方面要求：
首先，系统应具备对网络流量数据的统一接入与管理能力，支持原始流量数据与流量级特征数据的导入与组织。在特征构建层面，系统需支持多视图特征的独立生成与管理，保证统计特征、行为时间结构特征及多尺度频域特征等不同特征视图在统一框架下协同运行。在检测层面，系统应支持多模型分支加载与运行，并能够对多模型输出结果进行统一集成与判决。
其次，系统需保证检测流程的稳定运行与任务调度的可控性，支持检测任务配置、执行状态管理及结果持久化存储，能够满足实验验证与典型应用场景下的响应效率要求。
最后，系统架构应具备良好的模块解耦性与扩展能力，支持检测模型、特征视图及集成策略的动态调整与扩展，以适应后续研究迭代与方法优化需求。
综上所述，所设计系统需在流量数据管理、多视图特征构建、多模型检测与结果集成等方面形成完整支撑框架，为多视图特征模型集成方法的工程实现与应用验证提供系统化基础。
